# Stage C Lua emission

The development emitter accepts one closed definition with checked type
`Script Reply g`. It preserves that definition's tag index while checking
the Reply result requirement. Imports and source confinement use the
Stage B checker host. The full Client driver follows in Stage F.

```sh
dune build dev/lua_emit.exe dev/sha1_probe.exe
python3 -P dev/emit-lua.py --root examples M0Spine.tet -o .gatework/counter
node dev/extract-body.mjs .gatework/counter/body.wasm
sh dev/stage-c.sh
python3 -P dev/stage-c-redis.py
```

The last command runs a temporary loopback Redis server and stops its own
process in a `finally` block. It needs local socket permission. The main
Stage C ladder runs without a server. Both need the recorded OCaml, Dune,
Zarith and Python toolchain; the new gates also use LuaJIT, Node and
wasm-tools from `dev/TOOLCHAIN.md`. Use Python's `-P` flag as shown.

The output directory contains:

| File | Contents |
| --- | --- |
| `script.lua` | Canonical Lua 5.1 bytes, LF only, no BOM or final newline. |
| `script.json` | Entry name, SHA-1, derived `no_writes` boolean and physical keys encoded as hexadecimal bytes. |
| `body.wasm` | Import-free WasmGC byte carrier with `requestBody`, `scriptSha1`, `bytesEmpty`, `bytesHead` and `bytesTail` exports. |

`body.wasm` demonstrates the Stage C byte transport. It does not implement
the Client request loop, invoke code 10, SCRIPT LOAD caching or NOSCRIPT
fallback. Those belong to the hosts in Stage E. Stage D adds the Bash
artifact; no `prog.sh` is emitted here.

The printer reads inherited erased terms. It follows the reachable
function graph from the selected entry, including closure captures and
every case arm, and prints only those definitions. Functions are named
deterministically. The Lua runtime preserves tagged payloads, lexical
environments, partial and over-application, continuations and recursive
calls. All bindings are local. Physical keys must match a supplied KEYS
element; a missing key is a named runtime error. The key manifest collects
the literal key constructors produced by the M0 schema expansion.

An INCR executes in Redis, then a GET retrieves its exact decimal value.
The Lua number returned by INCR is discarded. That extra GET is inside
the atomic Lua invocation. Int64 replies cross the boundary as bulk
strings, including the signed minimum and maximum. GET preserves binary
strings and missing values; Reply status, error and nested array payloads
are converted explicitly. Command errors become Reply error values.

The `#!lua flags=no-writes` header comes from the reachable erased
operation set. An INCR in any reachable branch prevents that flag, even
if that branch is not taken in a particular run. Unrelated definitions
do not affect it. The result is conservative when a helper constructs
an operation that later becomes dead data. Cross-slot emission is still
outside this single-slot slice.

Unknown runtime globals, including native Nat arithmetic primitives,
receive `LUA-UNSUPPORTED`; delayed computations receive a named refusal.
Natural literals above 9007199254740991 are refused as `LUA-NAT-RANGE`.
Signed64 decimal bytes keep their full range. Checking and both erasure
passes share the explicit kernel budget, default one million polls.
Printer, SHA-1 and emitter resource exhaustion remain residual.

`print/transport.ml` checks a generated byte literal with the carried
reactor, erases it and calls the unchanged WasmGC emitter. Its lines count
inside the existing 320-line Lua bound alongside the printer, flags and
SHA-1. The resulting group measures 259 lines. A build-only Dune import
exposes the pinned Wasm library; no file in `vendor/kanon` changes.

Both preludes are pinned in `dev/PRELUDES.sha256`. The integrity gate
requires exactly those two paths, checks their bytes and prints their
109-line total. This addresses Stage B's unguarded prelude growth without
inventing the proposed eighth line bound. Any future prelude edit needs
an explicit manifest change visible in the diff.

Validation includes nine SHA-1 vectors, eleven Lua parses and Wasm
extractions, all six Reply variants, missing and binary values, captured
continuations, case payload scope, branch-derived write flags, signed
integer limits and three emission refusals. Removing `local` keeps the
body syntactically valid but trips the strict global environment. Adding
one final newline makes the extracted Wasm body differ. Five source
mutations exercise missing printer and transport files, a missing or
changed prelude, and an uncounted printer file. Every mutation restores
and reruns its positive control.
